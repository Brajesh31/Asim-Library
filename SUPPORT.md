## What to include in a support request

- Commit SHA.
- Operating system and compiler version.
- CMake version and generator.
- Build/test commands executed.
- Exact compiler or sanitizer output.
- Small input sequence that reproduces the issue.
- Expected versus observed behavior.

## What not to include

Do not share passwords, access tokens, private keys, private user data, or unrelated confidential information.

## Where to report

Use GitHub Issues for reproducible bugs, feature requests, and documentation improvements. Use private GitHub Security Advisories for security vulnerabilities.

## Current scope

This project is a local C++ library. It has no hosted service, runtime API, database, or customer support portal.
