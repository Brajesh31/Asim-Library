# FAQ

## Is this a production container library?

No. It is an educational implementation with integer-only structures and raw pointer ownership.

## Does it require CMake?

No. The documented GCC command is sufficient, although a future CMake build is planned.

## Which C++ version is required?

The examples target C++17 or newer.

## Does it use a database or network?

No. It is entirely local and in-memory.
