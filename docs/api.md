# API

## `Stack`

Construct with a capacity, then use `push`, `pop`, `peek`, `isEmpty`, `isFull`, `rotateLeft`, `rotateRight`, `display`, and `search`.

## `BST`

Use `insert`, `search`, and `inOrderTraversal`. The tree allocates nodes internally.

## `AVLTree`

Use `insert`, `search`, `deleteNode`, and `inOrderTraversal`. Rotations maintain AVL balance after insertion/deletion.

The current API returns integers and prints some operations to standard output. Empty and full behavior should be confirmed from the implementation before depending on it.
