## Screenshot policy

This repository is a native C++ library and has no graphical user interface. No application screenshots are included. The SVG banner and Mermaid diagrams are technical illustrations, not screenshots.

## Adding a visual

- Prefer SVG for scalable technical illustrations.
- Add meaningful alt text when embedding an image.
- Keep service/data labels accurate to the implementation.
- Do not depict planned functionality as implemented.
- Keep editable diagram sources in the documentation tree.
- Add new visuals to this inventory and validate relative paths.
