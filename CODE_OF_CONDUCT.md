# 🤝 Code of Conduct

## Our commitment

We want Asim-Library to be a respectful and technically constructive project. Contributors with different backgrounds, experience levels, and perspectives should be able to participate safely.

## Expected behavior

- Be respectful and assume good faith.
- Critique code and ideas, not people.
- Explain technical disagreements with evidence.
- Give actionable feedback.
- Welcome questions and beginner contributions.
- Respect privacy, confidentiality, and intellectual property.
- Acknowledge and correct mistakes.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, unwanted contact, publishing private information, credential exposure, deliberate disruption, and retaliation against good-faith reports are not acceptable.

## Reporting concerns

Contact the repository maintainer privately through GitHub for conduct concerns. Use SECURITY.md for security vulnerabilities rather than a public issue.

## Enforcement

Maintainers may remove harmful content, close discussions, restrict participation, or take other proportionate action. Serious or repeated violations may result in removal from project spaces. Enforcement should be handled consistently.

## Scope

This policy applies to repository issues, pull requests, reviews, discussions, and project-related communications.
